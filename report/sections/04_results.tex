\section{Results}
\label{sec:results}

\revision{\textbf{This section has been emptied rather than updated (12.08.2026).} Every quantitative
result it previously carried has been withdrawn, and it is left deliberately bare instead of being
qualified in place, because a caveated number in a results section is still read as a result. What was
removed and why is recorded below so that the withdrawal is auditable rather than a silent deletion; the
superseded values remain in the project record under
\code{docs/steps/corrections-and-dead-ends.md}, which is the appropriate place for measurements that no
longer hold.}

Three changes, each independent of the others, invalidate every measurement previously reported here.

First, the \textbf{training target was replaced} on 11.08.2026. The results were computed on an
area-under-the-curve value derived from CTRPv2's published table by dividing by a quantity that does not
represent the width of the integral, so the target itself was defective; and on a per-drug standardized
variant of it that has since been retired. The target is now the CurveCurator re-fit described in
Section~\ref{sec:target}, which is a different quantity rather than a rescaling of the old one.

Second, the \textbf{drug panel was rebuilt} on 12.08.2026 (Section~\ref{sec:panel}). The earlier results
were reported on compound sets chosen using our own response values --- a differential-response gate, and
a literature panel whose candidate list had been pre-ranked on the same statistic. Both selections are
withdrawn, so results reported over them describe a set of compounds that no longer defines the task.

Third, the \textbf{representations on disk predate the preprocessing corrections} recorded in
Section~\ref{sec:data}. The principal component baseline was computed under a doubly applied library-size
normalization and without per-gene standardization, and the transcript-level embeddings were produced
before the gene-symbol repair, which changes which genes reach the model at all.

No attempt is made here to say which of the previous qualitative conclusions will survive. Some plausibly
will --- the finding that a random split over cells leaks the label, because it follows from the label
being constant within a cell line rather than from any property of the target, is the clearest candidate.
But a conclusion that has not been re-measured on the corrected pipeline is a hypothesis about what the
re-measurement will show, and presenting it as a result is the error this project has already made twice.
The regeneration is a single pass over the whole pipeline, described in Section~\ref{sec:limitations};
this section is written once from its output.
